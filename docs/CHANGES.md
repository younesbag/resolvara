# Changes to shared config
- scaffold: @types/node pinned to ^22 (vitest 5 peer requirement); vitest.config.ts includes src/engine/**/*.test.ts with passWithNoTests; added Contribution type to src/engine/index.ts (referenced by SPEC but not defined there).
- ui: added dependency @phosphor-icons/react (icon library; package.json + lock). Removed create-next-app boilerplate from public/ and src/app/favicon.ico (replaced by src/app/icon.svg).
- ui: the column mapper sends these ColumnMapping keys to the engine (parseFile opts.mapping): id, createdAt, closedAt, customerKey, billed, billedValue, aiInvolved, aiInvolvedValue, humanReplied, reopenCount, csat, topicText, channel. The "...Value" keys hold the cell value(s) that mean yes (comma separated, case-insensitive). Defined in src/components/auditor/meta.ts (MAPPER_FIELDS); rename there if the engine uses other keys. The preset is passed as 'generic' or 'gorgias' when the mapper is used.
- ui: the worker peeks the first ~768 KB itself (Papaparse / JSON) to get headers and sample rows, then calls engine detectPreset(headers, sample). For nested JSON the sample rows contain both the original nested object and flattened dotted keys (e.g. "ai_agent.resolution_state"), and headers are the flattened dotted keys.
- ui: /benchmark reads from src/components/lib/benchmark.ts (loadBenchmark returns null until the Blob aggregation exists; replace its body, keep the BenchmarkRow shape). The contribute dialog POSTs the exact JSON it displays to /api/contribute and shows a clear message on 404/429/other errors.
- ui: GITHUB_URL in src/components/lib/links.ts is a placeholder (https://github.com/younesbag/resolvara) until the repo exists; override with NEXT_PUBLIC_GITHUB_URL.
- integration: vitest.config.ts now aliases `@` to `src` and also includes `src/server/**/*.test.ts` (contribution schema, rate limit, benchmark aggregation tests).
- integration: new server code in `src/server/contribution.ts` (zod schema, in-memory rate limit, benchmark aggregation) and `src/app/api/contribute/route.ts`; `src/components/lib/benchmark.ts` body replaced by the Blob aggregation (BenchmarkRow shape unchanged).
- integration: next.config.ts now sets the CSP and security headers on every route.
- review fixes: `vitest.config.ts` renamed to `vitest.config.mts` (ESM, removes the CJS warning) and `passWithNoTests` removed, so a run with no tests fails.
- review fixes: `next.config.ts` CSP no longer lists `https://vitals.vercel-insights.com` (`@vercel/analytics` posts to same-origin `/_vercel/insights`) and the HSTS header no longer says `preload`.
- review fixes: `src/engine/**` implemented (it was a stub): `types.ts`, `audit.ts`, `parse.ts`, `presets.ts`, `scan.ts`, `outputs.ts`, `sample.ts`, `hash.ts`, `time.ts`, `topic.ts`. Contract changes: new verdict `fail_unbilled`; `AuditReport` gains `judged`, `billedJudged`, `failUnbilled`; `Contribution.vendor` is the `ContributionVendor` enum (`CONTRIBUTION_VENDORS`); `contributionPayload(report, opts, vendor?)`; new `peekFile`. The mapper sends one more key, `csatScale` (`1-5` | `1-10` | `0-100` | `0-1`, empty = guess from the highest score).
- review fixes: the audit worker is created once on mount and reset with a `{type:"reset"}` message (protocol.ts); messages are queued and handled one at a time. `src/components/lib/benchmark.ts` and `src/server/contribution.ts` aggregate per vendor, over 7-day-window contributions only; `BenchmarkRow.preset` became `vendor`. `src/app/api/contribute/route.ts` names objects `<utc-day>-<payload hash>.json` with `allowOverwrite: true`.
- review fixes: `content/vendors.json`: Gorgias `presetSupport` is now `generic` (its export has no AI column, so it always goes through the mapper).
